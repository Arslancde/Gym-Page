# 💪 GYM - Fitness Website

A modern, responsive fitness website built with React.js.

## 🏋️ Features

- Full-screen sections with scroll animations
- Professional hero section with background zoom effect
- Responsive design for all devices
- Green theme with modern UI
- Blog and Shop sections
- Contact form with social links
- Interactive navbar with mobile menu

## 🛠️ Technologies Used

- React.js
- CSS3
- Parcel Bundler
- React Hooks

## 📦 Installation

```bash

git clone https://github.com/Arslancde/Gym-Page.git

# Go to project folder
cd Gym-Page

# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build
```

## How to Take Screenshots

### Method 1: Browser Developer Tools (Recommended)

1. Open your website: https://arslan-gym.vercel.app
2. Press `F12` to open Developer Tools
3. Press `Ctrl+Shift+P` (Windows) or `Cmd+Shift+P` (Mac)
4. Type "screenshot" and select:
   - **"Capture full size screenshot"** - for full page
   - **"Capture area screenshot"** - for specific sections

### Method 2: Manual Screenshots

| Section | How to Capture |
|---------|----------------|
| Hero Section | Scroll to top, take screenshot |
| About Section | Scroll down, take screenshot |
| Blog Section | Scroll to blog, take screenshot |
| Shop Section | Scroll to shop, take screenshot |
| Contact Section | Scroll to contact, take screenshot |
| Mobile View | Press `Ctrl+Shift+M` (toggle device toolbar) |
